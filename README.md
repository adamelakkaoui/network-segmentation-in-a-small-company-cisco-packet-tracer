# Network Segmentation in a Small Company – Cisco Packet Tracer

Academic Cisco Packet Tracer case study for logically segmenting a fictional 30-employee company network by department.

![Packet Tracer topology](images/topology.jpg)

## Project implementation

`network-segmentation.pkt` contains the Packet Tracer topology used for the project. The academic case study identifies four departments: Human Resources (10 workstations), Accounting (8), IT (6), and Management (6). Its objectives are broadcast reduction, logical isolation, inter-VLAN access control, and preparation for future services.

## Requirements and use

Install Cisco Packet Tracer and open `network-segmentation.pkt` to view the project topology and configurations.

## Project objectives

The case study applies VLAN-based segmentation to a fictional 30-employee company divided into four departments:

- Human Resources: 10 workstations
- Accounting: 8 workstations
- IT: 6 workstations
- Management: 6 workstations

The topology is designed to reduce broadcast domains, isolate departments logically, control inter-VLAN communication and provide a structured foundation for future network services.
